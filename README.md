## 🚀 Featured Projects

### 🔮 Andromeda: Oracle Task Management Bot
A Spring Boot + Telegram task-management platform built for an Oracle dev team through Atherion Systems, my Software Engineering course's student org. I served as **Product Owner and CTO** on a six-person team, taking the project from architecture to final delivery.

- **Stack:** Spring Boot microservices, Oracle Autonomous DB, Flyway, JPA, React/TypeScript, Telegram Bot, Groq/Gemini RAG layer
- **My part:** OKE infrastructure, CI/CD pipeline, HTTPS via cert-manager/Let's Encrypt, OAuth2/PKCE with OCI IAM, RBAC, blue-green deployment manifests, Qodana static analysis
- **Hardening:** OWASP ZAP and Sn1per scans with formal reports, DB privilege minimization, network security lists
- **Docs:** PGCS/IEEE 828, SRS, DIYAS architecture, risk matrix, quality and test plans
- **Result:** delivered mid-June 2026, and the final presentation ranked best in the cohort

[Frontend](https://github.com/AtherionSystems/Andromeda_web) · [Backend](https://github.com/AtherionSystems/Andromeda_db_API)
